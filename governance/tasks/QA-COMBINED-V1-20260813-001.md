## Failure classification

Return `CHANGES_REQUIRED` when any of these occurs:

- real ERP catalog cannot be loaded or produces materially distorted paths;
- original protected AY/PV files cannot be accepted with the correct password;
- service crashes/hangs or health becomes unavailable due to application blocking;
- password appears in any persisted/user-visible place;
- exact-first mapping semantics change;
- inline editor changes the wrong source row/months or hides other issues;
- export loses required rows/zeros/statuses;
- ADO/live-write path exists or is invoked.

A difference from the predicted `368/379` coverage is not automatically a code failure; report the actual evidence and classify the cause.
