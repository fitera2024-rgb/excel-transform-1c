# Excel → OPIU Light — пакет для локального тестирования

## 1. Что делает пакет

Сервис локально обрабатывает бюджетные Excel:

`Excel → проверка → преобразование → максимально полный preview → исправления → экспорт OPIU Light`.

В этой версии нет записи в 1С, ADO или внешнюю базу. Все действия выполняются локально на компьютере пользователя.

## 2. Требования

- Windows 10/11, 64-bit;
- 64-bit Python **ровно версии 3.11**, доступный через `python.exe` или Python Launcher;
- один свободный локальный порт из списка `8000`, `8765`, `8001`, `8010`, `8080`.

Wheel-файлы пакета собраны для Python 3.11 x64. Python 3.10, 3.12 и другие версии для этого пакета не подходят.

Интернет для установки библиотек не требуется: необходимые wheel-файлы находятся внутри пакета.

## 3. Запуск и остановка

1. Полностью распакуйте ZIP-архив в отдельную папку.
2. Дважды щёлкните `START_SERVICE.cmd`.
3. Перед стартом пакет автоматически останавливает предыдущие экземпляры именно `Excel → OPIU Light` на известных локальных портах. Другие приложения не останавливаются.
4. При первом запуске пакет создаст локальное окружение `.venv`.
5. Сервис запускается в фоне и браузер открывается автоматически.
6. Обычно используется адрес:

   `http://127.0.0.1:8000`

   Если порт занят другим приложением, пакет выберет следующий свободный порт и покажет точный адрес.
7. После успешного старта окно запуска можно закрыть — сервис продолжит работать в фоне.
8. Для ручной остановки дважды щёлкните `STOP_SERVICE.cmd`.

Не запускайте сервис прямо из ZIP-архива — сначала распакуйте все файлы.

В папке `runtime` создаются:

- `service.pid` — идентификатор текущего локального процесса;
- `service.url` — фактический адрес сервиса;
- `service.stdout.log` и `service.stderr.log` — журналы работы сервера.

## 4. Первичная загрузка справочников

Справочники загружаются один раз и сохраняются локально в папке `runtime`:

- ERP-статьи;
- организации и узлы;
- сценарии.

Ожидаемые контрольные значения для текущего набора:

- ERP-статьи: `271`;
- организации и узлы: `357`;
- сценарии: `12`.

После перезапуска справочники должны остаться доступными. Не удаляйте папку `runtime`, если нужно сохранить их между запусками.

## 5. Обработка бюджета

1. Выберите верхнюю ветку организаций.
2. Выберите организацию или нижний узел.
3. Выберите сценарий.
4. Укажите год.
5. Оставьте `Весь год` включённым либо выберите нужные месяцы.
6. Выберите бюджетный Excel.
7. Для защищённой книги введите пароль в поле формы. Пароль используется только для текущей локальной обработки и не сохраняется.
8. Нажмите `Построить preview`.

Для больших файлов отображается сообщение:

`Файл загружается и анализируется; не закрывайте страницу`.

## 6. Исправления и массовое подтверждение

Каждая проблемная исходная строка показывается отдельным блоком. Одна правка применяется ко всем 12 месяцам этой исходной строки без полного повторного запуска.

ERP-код выбирается по иерархии:

`Тип расходов → Группа расходов → Статья → ERP-код`.

Для строк, где путь и ERP-код уже полностью заполнены, доступно массовое действие:

1. Проверьте счётчик `Будет подтверждено: N строк`.
2. Поставьте галку `Подтверждаю все заполненные ERP-сопоставления`.
3. Кнопка изменит подпись с `Сначала поставьте галку` на `Применить все заполненные`.
4. Нажмите `Применить все заполненные`.

После успешного применения уже подтверждённые строки больше не предлагаются повторно. Появится сообщение, что новых заполненных сопоставлений нет.

Массовое действие:

- не подбирает и не меняет ERP-коды;
- подтверждает только полностью заполненные видимые значения;
- не подтверждает налоги, департаменты, ЦФО, суммы и read-only-проблемы;
- не скрывает остальные нерешённые причины;
- не создаёт дубли при повторном применении.

Незаполненные и неоднозначные строки остаются доступными для индивидуального исправления.

## 7. Экспорт

После проверки нажмите `Экспортировать OPIU Light`.

Экспорт содержит полный результат с сохранением нулевых значений, статусов `Требует внимания` и `Пропущено`. Для пропущенной месячной ошибки сумма остаётся пустой.

Если браузер показывает `ERR_CONNECTION_REFUSED`, запустите `START_SERVICE.cmd` ещё раз. Он остановит старые экземпляры сервиса, очистит известные порты и откроет актуальный адрес. Затем снова постройте preview, потому что незавершённый RUN хранится только в памяти текущего процесса.

## 8. Что сохранить при обновлении пакета

При переходе на новую версию:

1. запустите `STOP_SERVICE.cmd` в старой папке;
2. распакуйте новый ZIP в новую папку;
3. при необходимости скопируйте старую папку `runtime` в новую папку пакета;
4. не копируйте старую `.venv` — новый пакет создаст её самостоятельно.

## 9. Если сервис не запускается

- сообщение о Python: установите **64-bit Python 3.11** и включите `Add Python to PATH` либо Python Launcher;
- известный порт занят старым OPIU: повторный запуск остановит старый экземпляр автоматически;
- порт занят другим приложением: пакет не остановит его, а выберет следующий свободный порт;
- повреждён пакет: распакуйте исходный ZIP заново в новую папку;
- неверный пароль Excel: выберите файл повторно и введите правильный пароль;
- экран заблокирован: используйте действие сброса/повторного выбора файла;
- сервис завершился: проверьте `runtime\service.stderr.log` и `startup.log`.

## 10. Границы версии

- нет ADO-записи;
- нет записи в 1С;
- нет live write во внешнюю базу;
- поддерживаются `.xlsx` и `.xlsm`, включая совместимые защищённые OOXML-книги;
- формулы читаются по сохранённым в Excel значениям — сервис не является движком пересчёта Excel.
