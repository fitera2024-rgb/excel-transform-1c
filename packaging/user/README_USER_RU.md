# Excel → OPIU Light — пакет для локального тестирования

## 1. Назначение

Сервис локально выполняет:

`Excel → проверка → преобразование → максимально полный preview → исправления → экспорт OPIU Light`.

Записи в 1С, ADO и внешнюю базу в этой версии нет.

## 2. Требования

- Windows 10/11 x64;
- Python 3.11 x64;
- один свободный порт из `8000`, `8765`, `8001`, `8010`, `8080`.

Интернет для установки библиотек не требуется: wheel-файлы находятся внутри ZIP.

## 3. Запуск и остановка

1. Полностью распакуйте ZIP в новую папку.
2. Запустите `START_SERVICE.cmd`.
3. Пакет остановит предыдущий экземпляр именно этого сервиса на известных портах, не затрагивая чужие приложения.
4. При первом запуске будет создана `.venv`; затем откроется браузер.
5. Сервис работает в фоне после закрытия стартового окна.
6. Для остановки используйте `STOP_SERVICE.cmd`.

Фактический адрес хранится в `runtime\service.url`; журналы — в `startup.log` и `runtime\service.stderr.log`. Не запускайте пакет прямо из ZIP.

## 4. Справочники

Один раз загрузите:

- ERP-статьи;
- организации и узлы 1С;
- сценарии;
- классификатор ЦФО Инталев.

Контрольные значения текущих ERP-справочников: `271 / 357 / 12`. Количество ЦФО Инталев зависит от загруженного классификатора. Все каталоги сохраняются в `runtime\local.db` и доступны после restart.

## 5. Обработка бюджета

1. Выберите верхнюю ветку и конкретную организацию/узел 1С.
2. Выберите сценарий, год и `Весь год` либо месяцы.
3. Выберите бюджетный Excel.
4. Для защищённой книги введите пароль в поле формы — он не сохраняется.
5. Нажмите `Построить preview`.

Для большого файла показывается `Файл загружается и анализируется; не закрывайте страницу`.

## 6. ERP-сопоставления

ERP-код выбирается по иерархии `Тип → Группа → Статья → ERP-код`.

Для массового действия:

1. проверьте `Будет подтверждено: N строк`;
2. поставьте `Подтверждаю все заполненные ERP-сопоставления`;
3. нажмите `Применить все заполненные`.

Уже подтверждённые строки показываются статусом и повторно не входят в счётчик. Другие причины строки сохраняются.

## 7. Налогообложение не требуется

Для строки с неопределённым налогом можно выбрать `Налогообложение неважно`. Сервис покажет `Налогообложение: не требуется`, не подставляя НДС или другой режим.

Для всех подходящих строк используйте отдельную галку `Подтверждаю для всех строк: налогообложение неважно` и кнопку `Применить всё`. Счётчик показывает исходные строки, а не месяцы.

## 8. Сопоставление ЦФО Инталев

В верхнем блоке preview каждый уникальный ЦФО Инталев имеет:

- код/наименование/путь;
- число исходных строк;
- иерархический выбор конкретного узла 1С.

Можно подтвердить одно соответствие либо заполнить несколько, поставить `Подтверждаю все заполненные сопоставления ЦФО` и нажать `Применить всё`. Одно соответствие обновляет все строки и месяцы этого ЦФО. Оно сохраняется локально и повторно применяется после restart.

Сервис не объединяет похожие названия и не делает fuzzy-сопоставление. При неоднозначности нужен точный выбор/исправленный классификатор.

## 9. Экспорт

Нажмите `Экспортировать OPIU Light`. Экспорт сохраняет месяцы, нули, отрицательные значения, подтверждённые ERP/ЦФО, `Не требуется`, статусы `Требует внимания` и `Пропущено`.

## 10. Обновление пакета

1. Остановите старый пакет через `STOP_SERVICE.cmd`.
2. Распакуйте новый ZIP в новую папку.
3. Для сохранения каталогов скопируйте старую папку `runtime` в новый пакет.
4. Старую `.venv` не копируйте.

## 11. Диагностика

- Python не найден: установите Python 3.11 x64 и Python Launcher/Add to PATH;
- `ERR_CONNECTION_REFUSED`: снова запустите `START_SERVICE.cmd` и откройте адрес из `runtime\service.url`;
- неверный пароль: выберите файл повторно;
- ошибка сервера: пришлите `startup.log` и `runtime\service.stderr.log`;
- незавершённый RUN после restart нужно построить заново, поскольку RUN хранится в памяти процесса.

## 12. Границы

Нет ADO, записи в 1С и live write. Поддерживаются `.xlsx`/`.xlsm`, включая совместимые защищённые OOXML-книги. Формулы читаются по сохранённым Excel-значениям.
