До принятия владельцем реализацию не начинать.

## Предварительный путь

1. Пользователь выбирает организацию и период, если они нужны бизнес-процессу.
2. Выбирает Excel.
3. Сервис проверяет структуру и данные.
4. Ошибки показываются простым русским языком с понятным способом исправления/перевыбора.
5. Сервис выполняет трансформацию.
6. Пользователь видит preview и сводные количества.
7. Пользователь скачивает/принимает результат.

## Не входит в первую vertical slice

- ADO live write;
- запись в production 1С;
- автоматический merge/release;
- технические SHA/path/debug controls в normal UI.

## Визуальный reference

Можно использовать из OPIU: верхнюю навигацию, карточки состояния, организацию/период, работу с файлами, иерархию статей и журнал. Не копировать тяжёлую внутреннюю логику OPIU.
