# Product Contract

STATUS: `DRAFT / OWNER_INPUT_REQUIRED`

## Цель

Создать лёгкий внутренний сервис для цепочки:

`Excel → validation → transformation → preview → later ADO DRY RUN → controlled 1C write`.

Точная бизнес-цель, пользователи, входы, правила трансформации и результат будут заполнены после анализа примеров владельца.

## Жёсткие границы старта

- OPIU используется только как визуальный/UX reference и источник проверенных safety-паттернов.
- Не копировать R005, R001, Rules Engine и source-proof UI.
- Первая vertical slice не пишет в 1С/БД.
- Live write по умолчанию запрещён.
- Production — отдельный owner gate.

## Owner input required

Нужно определить:
- кто пользователь;
- какую ручную работу заменяет сервис;
- типовые Excel;
- ожидаемый результат;
- организации и период;
- иерархию статей;
- правила преобразования;
- что должно происходить при ошибках/неизвестных значениях.
